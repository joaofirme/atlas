# Atlas

Base de conhecimento de dados e negócio da Farmax: significado dos indicadores, cálculo, dados, dimensões, relações, uso em relatórios e procedimentos de análise.

Comece pelo [guia de consulta](docs/consulta.md). Para navegar manualmente, use o [catálogo de negócio](docs/catalogo.md). Para investigar carteira, veja o [procedimento analítico](skills/comercial/analisar-carteira/SKILL.md).

Os contratos atuais são rascunhos extraídos de uma fonte: não há certificação de negócio nem acesso a valores atuais neste repositório. A conexão de execução aos dados ainda precisa ser implementada.

Para manter o conteúdo: [instruções](.agents/skills/atlas-documentation/SKILL.md), [plano e avaliação](docs/decisoes/0002-consulta-progressiva.md) e [próximas etapas](docs/roadmap.md). Evidências e detalhes de apresentação ficam no [inventário técnico](docs/catalogo-tecnico.md).
